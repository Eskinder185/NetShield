# Privacy model

Principles: collect the minimum, local-first where possible, consent for anything about other people's devices, easy export and deletion, no third-party calls by default.

| Data | Purpose | Condition | Retention | Notes |
|---|---|---|---|---|
| Email, display name, bcrypt hash | Account | Always | Until account deletion | |
| Measurements (kind, target, success, latency, time) | Diagnosis | Sensor running | `retention_days` (default 30, max 365), hourly purge | No traffic content or browsing data |
| Device: hash of MAC, IP, hostname, vendor guess, user labels | Unknown-device alerts | `consent_device_inventory` = true **and** agent flag + approved CIDR | Until data deletion | Raw MAC never stored; randomized addresses flagged |
| Findings/incidents/verifications | Alert & retest history | Generated by above | Until data deletion | |
| Audit events | Accountability | Key actions | Until household deletion | |
| Pasted URLs (Scam Shield) | Analysis | User action | **Not stored, not logged** | Sent to the NetShield API as text only |

Controls: JSON export and CSV export (`/export`), delete collected data (owner), delete account (password required; deletes sole-member households by cascade), consent toggle, retention setting.
Third parties: none. No analytics, fonts, AI, email, or payment calls. AI is not wired in.
Demo mode keeps synthetic data in browser memory only.
Known gaps: audit log not purged on data deletion; no per-user data-subject request tooling beyond export/delete; no hosted-service DPA.
